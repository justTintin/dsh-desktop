## 1. 一条原则：规范 = 匹配成功率

文案混剪的"自动匹配素材"不是随机抽——系统按下面四步为每个分镜镜头挑选素材：

| 步骤 | 系统看什么 | 来源 |
| --- | --- | --- |
| ① 景别同桶 | 素材的**景别标注** vs 分镜的景别 | 服务端分割/分析 |
| ② 时长窗 | 素材段时长是否落在 **分镜时长 × 0.8 ~ × 1.5** 区间 | 服务端分割 |
| ③ 评分排序 | 素材**画质评分**高者优先 | 服务端分析（满分 10） |
| ④ LLM 语义精选 | 素材**画面描述**与分镜**画面描述**的语义一致性 | 服务端分析 + 分镜脚本 |

**你拍的每一条素材，最终被这四样东西代表：景别、时长、评分、画面描述。**
它们全部来自服务端对归档素材的**自动分割与分析**。所以：

- 拍的时候就要想清楚"这条素材是哪类镜头、给哪个分镜用"；
- 拍完只负责**按规范命名 + 归档到 NAS 品类目录**；
- 分割、评分、分析由服务端自动完成，使用前核对结果即可；
- **景别由服务端 shot_analysis 自动标注**，客户端不做推断——拍摄时画面
  清晰可辨即可，不需要人工标注景别；
- 同一文件**重复归档无害**：服务端按"同源片同一起止"自动去重，重复导入
  不会产生重复素材。

## 2. 前期拍摄规范（必拍必守）

### 2.1 固定四大拍摄镜头维度（必拍）

所有产品统一按**入场、出场、中景、特写**四类镜头拍摄（与系统景别桶一一对应）：

| 镜头 | 系统键 | 拍什么 | 成片用途 |
| --- | --- | --- | --- |
| 入场 | `entrance` | 产品整体入画过程，平稳顺滑，突出完整外观 | 开篇引流，建立第一视觉认知 |
| 出场 | `exit` | 收尾展示画面，构图完整、画面干净 | 转场收尾、镜头衔接 |
| 中景 | `medium` | 完整呈现整体形态、外观设计、主体细节 | **成片主力素材** |
| 特写 | `closeup` | 核心卖点、细节工艺、功能按键、材质纹理 | 卖点强调、提升说服力 |

> ⚠️ 一条素材里**不要混多种景别**（如一条里既推近特写又拉远全景）——
> 系统按"条"匹配景别，混合素材会被归错桶或浪费。

> 📌 **落实到归档与命名**：景别必须写入文件名第 2 段（固定四值之一，见 §4.2），
> 归档后按景别段分组统计，**四桶齐备**才算归档完成（核对表见 §4.4）。

### 2.2 拍摄硬性标准（全员统一执行）

- **画面环境**：背景极简干净、无杂物、无杂乱光影、无多余入画元素；按店铺要求
  拍日常风或电竞风背景，核心是产品主体突出；
- **画面稳定性**：无抖动、无摇晃、无运镜卡顿，镜头流畅自然；
- **画面清晰度**：对焦精准，全程无虚焦、无模糊、无过曝欠曝，画质高清通透；
- **单条素材时长**：控制在 **10 秒以内，优先 5 ~ 9 秒**优质短素材（适配后续
  掐头去尾、镜头分割规则）；
- **分辨率与方向**：分辨率不低于 1080×1920（竖屏）；**横竖屏在命名中标明**
  （见 §4.2），竖屏为成片主用方向；
- **格式**：MP4（H.264）。

### 2.3 拍摄专项注意（适配后期掐头去尾）

后期镜头分割会对 9 秒左右素材**掐头去尾，截取中间 3 ~ 4 秒最优画面**，因此：

- 素材开头、结尾**无需预留空镜**；
- **核心卖点、细节展示务必保留在素材中间段落**，避免优质画面被裁掉；
- 一个动作拍完整（起幅到落幅），半截动作分割后不可用。

### 2.4 一条素材 = 一个动作 / 一个主体

LLM 语义精选读的是素材的**画面描述**（服务端分析生成）。画面越单一、主体越
明确，描述越准、匹配越稳：✅ 一条 = 一个动作；❌ 一条 = 开箱+演示+收纳全流程。
画面里避免无关人物/品牌/水印入镜（会污染画面描述）。

### 2.5 产品一致性

同一产品的所有素材，品牌 / 型号 / 品类信息必须一致——素材库按这三个维度
过滤，不一致会导致同产品素材散落在不同过滤结果里，匹配池变少。

## 3. 素材数量配比（量化模板）

- 基础配比公式：**目标产出 5 条成片 → 储备 20 条优质素材**；
- 批量出片通用标准：**素材总量 = 成片数量 × 4**，保证镜头不重复、画面差异化充足。

## 4. 归档与命名（含分辨率 / 横竖屏）

**分工先说清楚**：拍摄人员负责**按规范命名 + 归档到 NAS 品类目录**；之后的
**评分过滤、分割、分析全部由服务端自动完成**（分割产物由服务端自动命名，
如 `split-<源>_shot_001.mp4`）。

### 4.1 归档位置（NAS 品类目录）

```
NAS/<品类>/                     ← 品类目录即归档目的地（如：NAS/鼠标键盘/）
  <按 §4.2 规范命名的素材文件>
```

### 4.2 归档命名格式（景别 + 分辨率 + 横竖屏）

```
品名_景别_内容描述_分辨率_横竖屏_序号.mp4

示例：
  保温杯_入场_产品整体入画_1080x1920_竖屏_01.mp4
  保温杯_出场_收尾定格展示_1080x1920_竖屏_02.mp4
  保温杯_中景_全貌横移展示_1080x1920_竖屏_03.mp4
  保温杯_特写_杯口细节_1080x1920_竖屏_04.mp4
  键盘_中景_全貌横移展示_1920x1080_横屏_01.mp4
```

规则：

| 段 | 要求 |
| --- | --- |
| 品名 | 与产品库登记一致（品牌+品名可连写） |
| **景别** | **固定四值之一：入场 / 出场 / 中景 / 特写**（对应 §2.1 四类镜头；服务端分析后与该段对照复核） |
| 内容描述 | 这条素材"拍的是什么"（≤12 字，与景别分类对应） |
| **分辨率** | **实际像素 宽x高**（竖屏如 `1080x1920`，横屏如 `1920x1080`；2K/4K 按实际填） |
| **横竖屏** | `竖屏` / `横屏` 二选一 |
| 序号 | 两位数字（01 起），同景别同描述多条时递增 |

通用规则：下划线 `_` 分隔、顺序固定；只用中文、字母、数字、下划线；**禁用**
空格、`#` `%` `&` `@` 及表情符号；扩展名统一小写 `.mp4`。

> 为什么景别要单独成段：①归档后按段分组即可核对**四桶覆盖**（不用打开文件）；
> ②服务端分析出的景别可与命名景别**逐条对照**，不一致 = 分析误判或拍摄意图
> 不清。注意：系统匹配仍以**分析景别**为准，命名段是人工核对与覆盖统计的锚点。

### 4.3 归档后禁止改动

归档完成（服务端开始扫描）后**不得再改名、移动、删除** NAS 目录内的文件——
分割产物与素材库记录都指向这些原文件，变动会导致素材失效。要补拍/替换，
新增文件归档即可。

### 4.4 四桶覆盖核对（归档后、扫描前）

按文件名第 2 段（景别）分组统计，**每个产品的四桶齐备**才算归档完成：

| 景别 | 建议占比（成片数 ×4 的素材池） | 缺项时 |
| --- | --- | --- |
| 中景 | ≥50%（成片主力） | 补拍产品全貌/主体展示 |
| 特写 | ~25% | 补拍核心卖点/细节 |
| 入场 | ~15% | 补拍开篇入画镜头 |
| 出场 | ~10% | 补拍收尾镜头 |

占比为**建议值**（中景是成片主力，可按运营调整）；但**任一桶为 0 = 拍摄缺项，
必须补拍**。核对完成后交服务端扫描，扫描开始后文件冻结（§4.3）。

## 5. 服务端自动处理（归档之后无需人工）

归档完成后，服务端自动执行，人工只做核对：

| 环节 | 规则 | 人工核对点 |
| --- | --- | --- |
| 评分过滤 | 画质/运镜/完整度/氛围综合打分（满分 10）：高品质成片线 **≥7 分**；普通流量线 5~6 分可调。注：当前评分普遍偏低，按实际判断 | 过滤阈值设置 |
| 智能分割 | 9 秒左右素材**掐头去尾，取中间 3~4 秒**最优画面 | 分割没有切碎动作 |
| 景别/描述分析 | 每段标注景别、生成画面描述 | 景别与拍摄意图一致、描述准确 |
| 入库 | 分割段进入素材库，供文案混剪匹配 | 素材库能按品类/品牌检索到 |

## 6. 成片制作操作提示（对应文案混剪卡片四步）

以下与"文案混剪"卡片的四个步骤一一对应，此处只列关键规范：

1. **步骤 1 · 文案编写**：输入/生成文案 → AI 生成分镜脚本（每镜景别/时长/
   画面描述）→ NAS 归档素材导入并自动分割 → 智能匹配（§1 四步）→ 人工微调；
2. **步骤 2 · 口播配音**：先做**数字口语化修正**（Pura 80 → Pura 8零；
   1.4 → 1点4）→ 音色按产品风格选（数码选活力）、情绪/语速微调 → **批量克隆
   合成**，统一全批次风格；
3. **步骤 3 · 视频素材**：镜头重组与自定义——成片时长（默认 30 秒，可
   15/20/40）、成片数量（参考系统推荐）、转场与出入场加速、镜头顺序拖拽、
   实时预览校验；
4. **步骤 4 · 特效包装**：花字优先给型号/卖点/优惠；字幕参数模板化统一，双
   预览校验；BGM 素材库选取或系统生成（免版权），音量低于人声；最后**导出
   剪映草稿**，逐片排查卡顿/音画不同步/字幕错误后批量出片。

## 7. 常见错误与后果

| 错误 | 系统表现 | 后果 |
| --- | --- | --- |
| 素材分析没完成就要求匹配 | 无景别/评分/画面描述 | 匹配选不中或排序垫底 |
| 命名缺分辨率/横竖屏 | 选材分池困难，横竖混裁 | 成片构图不可控 |
| 命名景别段缺失或取值超出四值 | 四桶覆盖核对无法统计 | 缺项发现滞后，补拍不及时 |
| 文件名景别段与分析景别不一致 | 以分析为准入池 | 暴露拍摄意图不清或分析误判，需人工复核 |
| 归档到错误品类目录 | 进错素材过滤池 | 按品类筛选时找不到 |
| 归档后改动/移动/删除 NAS 文件 | 素材库记录与文件脱节 | 预览/合成取不到文件 |
| 一条素材混多动作 | 画面描述模糊 | LLM 匹配语义漂移，成片镜头跳戏 |
| 评分 <7 的素材用于高品质成片 | 成片质感下降 | 按成片定位调过滤线 |
| 横屏素材混入竖屏成片 | 合成裁切/留黑边 | 成片构图不可控 |

## 8. 快速检查清单

**拍摄中**：四类镜头齐 → 单条 5~9 秒（≤10）→ 核心卖点在中间段 → 背景干净稳定清晰。

**归档前**：命名六段齐（**景别**为四值之一 + **分辨率+横竖屏**）→ 无水印字幕 → 单动作单主体 → 竖屏 ≥1080×1920。

**归档后**：四桶覆盖核对齐备（§4.4）→ 扫描/分割/分析完成 → 景别与描述逐条核对（文件名段 vs 分析结果）→ 品类/品牌过滤能查到全部素材 → 智能匹配结果人工过目。
