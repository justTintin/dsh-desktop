# 定制功能合入核查清单

> 版本：v1.0 ｜ 2026-09-27 ｜ 适用：tintin-dsh-desktop（fork）每次合入上游
> dsh-desktop 代码之后、打包之前
>
> **用途**：上游合入（absorb / merge / rebase）可能静默冲掉 TinTin 定制。本文
> 是定制功能清单 + 逐项核查命令，合入后整表跑一遍，**FAIL>0 禁止打包**。
>
> **判定原则**：某定制点不存在了，先查执行文档与提交历史——有裁决/提交记录
> 的属"有意适配"（更新本清单），无任何记录的消失 = **意外丢失**（回滚或补回）。
> 测试全绿 ≠ 定制还在：vitest 模块垫片会让坏代码在测试里全绿、真实启动才炸
> （2026-09-25 ytdlp-logic 启动事故），所以每轮都含"真实启动观察"项。

---

## 0. 使用方法

1. 上游合入完成后，在本仓库根目录执行 §6 的一键核查脚本（Git Bash）；
2. `FAIL>0` → 按 §1~§5 的定位说明修复；全部 PASS → 继续跑 §5 的测试与
   真实启动观察；
3. 打包（Release-Builder）→ 打包后再跑一遍脚本核对产物目录；
4. 有新增定制（新卡片/新通道/新工具）时，**先在本清单登记锚点，再合入**。

## 6. 一键核查脚本（Git Bash，复制整块执行）

```bash
cd /d/Project/tintin-dsh-desktop || exit 1
pass=0; fail=0
chkGE() { d="$1"; e="$2"; a="$3"   # 计数锚点：实际 ≥ 最小期望（只增不减，避免误报）
  if [ "$a" -ge "$e" ] 2>/dev/null; then echo "PASS  $d（$a）"; pass=$((pass+1))
  else echo "FAIL  $d （实际 $a，低于下限 $e）"; fail=$((fail+1)); fi; }
chkZero() { d="$1"; a="$2"         # 反向锚点：必须为 0
  if [ "$a" = "0" ]; then echo "PASS  $d"; pass=$((pass+1))
  else echo "FAIL  $d （应无而有无：$a）"; fail=$((fail+1)); fi; }

chkGE "1.1 setName TinTin"            1 "$(grep -c "app.setName('TinTin')" src/main/index.ts)"
chkGE "1.2 appId com.tintin.desktop"  1 "$(grep -c 'com.tintin.desktop' package.json)"
chkGE "1.3 服务端种子/provider"        3 "$(grep -cE 'DEFAULT_SERVER_URL|ensureTinTinProvider' src/main/tintin-first-boot.ts)"
chkGE "1.7 默认工作区注册 tintin-workspace"  2 "$(grep -c 'tintin-workspace' src/main/tintin-first-boot.ts)"
chkGE "1.4 模型服务商默认指向 tintin-server" 5 "$(grep -c 'tintin-server' src/main/tintin-first-boot.ts)"
chkGE "1.5 /llm baseURL 锚点"                2 "$(grep -c 'baseURL' src/main/tintin-first-boot.ts)"
chkGE "1.6 agent-default-model"             1 "$(grep -c 'agent-default-model' src/main/tintin-first-boot.ts)"
chkGE "2.1 退出连树杀"                 3 "$(grep -c 'killWindowsProcessTree' src/main/runtime/harness-runtime.ts)"
chkGE "2.2 pid 契约 getter"           1 "$(grep -c 'get pid' src/main/runtime/disclaimed-utility-process.ts)"
chkGE "3.1 工具注册隔离 registerTool"  4 "$(grep -c 'registerTool({' packages/tintin-bundle/index.js)"
chkGE "3.2 [bridge] 全量追踪"          1 "$(grep -c '\[bridge\]' packages/tintin-bundle/index.js)"
chkGE "3.3 context:writeTask"         1 "$(grep -c 'context:writeTask' packages/tintin-bundle/index.js)"
chkGE "3.4 SSE 透传路由"               1 "$(grep -c 'tintin/sse' packages/tintin-bundle/index.js)"
chkGE "3.5 workflow_type 防保留键"     3 "$(grep -c 'workflow_type' packages/tintin-bundle/lib/agent-tools.js)"
chkGE "3.6 presets 五角色"             5 "$(ls packages/tintin-bundle/presets | wc -l)"
chkGE "3.6b presets task.json 指引"    5 "$(grep -rl 'task.json' packages/tintin-bundle/presets | wc -l)"
chkGE "3.8 素材使用上报器接线"           2 "$(grep -c 'createMaterialUsageReporter' packages/tintin-media-bundle/src/composables/copywritingMontage/useCopywritingMontageStep4Final.ts)"
chkGE "4.1 卡片挂载链"                12 "$(grep -cE 'v-if="active ===|v-else-if="active ===' packages/tintin-media-bundle/src/App.vue)"
chkGE "4.1b P2 四卡逐一挂载"            4 "$(grep -cE 'v-else-if=..active === .(video-transcribe|subtitle-removal|viral-clone|live-slice).' packages/tintin-media-bundle/src/App.vue)"
chkGE "4.2 作用域根 border-box"        2 "$(grep -c '^.tintin-media-scope {' packages/tintin-media-bundle/src/styles/tintin-global.css)"
chkGE "4.3 契约链文件"                 4 "$(ls packages/tintin-media-bundle/src/types/api-contract.generated.ts packages/tintin-media-bundle/src/types/server-api.ts packages/tintin-media-bundle/src/types/server-api-montage.ts packages/tintin-media-bundle/src/types/server-api-audio.ts 2>/dev/null | wc -l)"
chkGE "4.5 [tintin][bridge] 渲染层兜底" 1 "$(grep -c '[tintin][bridge]' packages/tintin-bundle/client.js)"
chkGE "4.6 composer-left 挂载"         4 "$(grep -c 'conversation.input.left' packages/tintin-media-bundle/src/client-entry.ts)"
chkGE "5.1 清扫宏 customCheckAppRunning" 2 "$(grep -c 'customCheckAppRunning' build/installer.nsh)"
chkGE "5.2 清扫收窄 INSTDIR"           4 "$(grep -c 'INSTDIR' build/installer.nsh)"
chkGE "5.3 GameBar 固化"               1 "$(grep -c 'UseNexusForGameBarEnabled' build/installer.nsh)"
chkGE "5.5 Defender 排除 tintin"       3 "$(grep -c 'APPDATA.tintin' build/installer.nsh)"

chkZero "5.4 无跨产品 session.json 删除" "$(grep -c 'Delete \\"$APPDATA/dsh-desktop' build/installer.nsh)"

echo "────────────────────────"
echo "核查结果：PASS=$pass FAIL=$fail"
[ "$fail" = 0 ] && echo "✅ 定制锚点齐全，可继续 §7 测试与真实启动观察" || echo "❌ 存在丢失项，按 §1~§5 定位修复后重跑"
```

## 7. 测试与真实启动观察（锚点通过后的第二层）

**真实启动观察**（测试绿 ≠ 定制还在）：

1. 启动后顶部 Tab 栏四项（工作台/运营工具/媒体工具/浏览器）在位；
2. 媒体工具 12 张卡齐全、逐卡打开有内容（防挂载链半接线）；
3. 选择产品/素材面板正常出数据（防桥路由丢失复发——405 事故面）；
4. 剪映草稿导出成功后，harness.log 出现 `[bridge] ... -> ok` 行（追踪在位）；
5. 退出应用无残留捆绑 node 进程（连树杀在位，防 EPERM 复发）。
